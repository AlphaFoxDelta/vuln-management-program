# Exception Request

File before the SLA expires. Exceptions are documented risk acceptance,
signed by two people, with an expiry date. No permanent exceptions.

- Finding ID:
- Title and severity:
- Requested by: (Remediation Owner)
- Date submitted:
- Why the SLA cannot be met: (be specific; "no time" is not a reason)
- Compensating controls in place: (what reduces exposure right now, with evidence)
- Residual risk: (what could still happen, in plain language)
- Proposed expiry date: (exceptions expire; max 90 days, then re-justify)
- Remediation plan during exception: (what happens before expiry)
- Program Owner review: (name, date, approve / deny)
- Executive Sponsor sign-off: (name, date)

If denied, the original SLA stands. If expired without renewal, the finding
returns to breached status at its original severity.
